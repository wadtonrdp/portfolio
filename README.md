## 👋 Quem sou eu

Sou desenvolvedor frontend apaixonado por criar interfaces que combinam **boa estética com funcionalidade real**. Estou no 3º semestre de **Análise e Desenvolvimento de Sistemas** na **UniSenai** (Cuiabá/MT) e construo projetos do zero — com banco de dados real, APIs externas e atenção a cada detalhe de UX.

Me identifico muito com a interseção entre **desenvolvimento e design**: acredito que um bom produto começa por uma experiência bem pensada. Estou sempre buscando evoluir, seja aprendendo uma nova tecnologia ou refinando o que já sei.

> 💼 **Aberto a oportunidades de estágio e vagas júnior.**

### O que o Moneto faz

| Feature | Detalhe |
|---|---|
| 💹 Preços ao vivo | BTC, ETH e criptos via CoinGecko — auto-refresh a cada 60s |
| 💵 Câmbio USD/BRL | Tempo real via Frankfurter API |
| 🗄️ Banco de dados real | Supabase com sessões isoladas — cada usuário tem seus próprios dados |
| 📄 Exportação PDF | Layout com branding, tabela de transações e resumo financeiro |
| 📊 Relatórios dinâmicos | Gráficos e métricas calculados dos dados reais, filtrável por período |
| 🔔 Notificações | Sistema de lidas/não lidas persistido |
| ➕ CRUD completo | Adicionar e remover transações e ativos em tempo real |

### Stack do Moneto

```
Next.js 16  ·  React 19  ·  TypeScript  ·  Tailwind CSS v4
Supabase  ·  Recharts  ·  CoinGecko API  ·  Frankfurter API
```
